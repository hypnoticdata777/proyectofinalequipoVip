1. Introducción

La presente matriz de trazabilidad ha sido elaborada para el proyecto USF Portal – Sistema Escolar Integral, un portal web para la gestión académica, inscripciones, calificaciones, pagos y notificaciones de una institución universitaria. La matriz relaciona cada requerimiento identificado con los casos de uso correspondientes, los módulos o componentes del sistema, las pruebas asociadas y el estado actual de implementación, permitiendo asegurar el seguimiento y cumplimiento de cada necesidad del sistema.

2. Identificación de Requerimientos
